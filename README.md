# ☕ Cafe Management System

A simple terminal-based Cafe Management System 
built with Python. The user can view the cafe menu, 
select items, place an order and automatically get 
the total bill calculated. Designed for beginners 
to understand how Python can be used to build 
real-world management systems.

## 📌 About
This project simulates a basic cafe ordering system. 
When the program runs, it displays a menu with items 
and prices. The user selects what they want to order 
and the system asks if they want to add one more item. 
Once done, the final bill is calculated and displayed.

## 💡 How It Works
1. Program displays the cafe menu with prices
2. User selects an item to order
3. System asks - **"Do you want to add one more item? (yes/no)"**
4. If **yes** → user selects one more item
5. If **no** → final bill is calculated and displayed
6. Prices are stored and fetched using a dictionary

## 🔑 Concepts Used
- `dictionary` - to store menu items and prices
- `conditional statements` - to handle program logic
- `if-else` - to handle yes/no choice
- `user input` - to take orders from user

## 🛠️ Technologies Used
- Python 3.x
- Built-in concepts only ( `dictionary`, `conditional statements` )
